JFrog has introduced MCP (Model Context Protocol) enabled self-service trials, allowing developers to use AI coding agents like Cursor and Claude to automate platform setup and operations without manual intervention. The MCP server enables users to execute commands through natural language queries across Artifactory, Xray, distribution, and other JFrog platform components. This enhancement simplifies evaluating the JFrog Platform during free trials by allowing agents to handle tasks like creating projects, checking vulnerabilities, and managing repositories.
